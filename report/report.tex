\section{Introduction}
% ─────────────────────────────────────────────────────────────────────────────

Sports broadcasting produces enormous quantities of footage that fans consume
selectively—spectators rarely watch a full match but are intensely interested in
key moments such as sixes, wickets, or boundary shots. Manually curating these
highlights is labour-intensive and does not scale. Automatic highlight
generation therefore has significant commercial and practical value for
broadcasters, streaming platforms, and fan engagement tools.

The emerging task of \emph{video-to-video moment retrieval} (V2VMR) offers a
principled solution. Given a short \emph{query} video exemplifying an action
(\textit{e.g.}, a six shot) and a long \emph{target} video (\textit{e.g.}, a
full cricket match), the system must locate every temporal window in the target
where the same action occurs. This is fundamentally harder than text-based
moment retrieval~\cite{lei2021qvhighlights} because the model must align two
variable-length visual sequences without access to language descriptions.

In this project we apply \textbf{MATR} (Aligning Moments in Time using Video
Queries, ICCV~2025)~\cite{kumar2025matr}—a transformer-based V2VMR
architecture—to the problem of automated cricket highlight generation. We train
and evaluate MATR on the large-scale \textbf{SportsMoments} dataset and
experiment with two visual feature encoders: CLIP~\cite{radford2021clip} and
ImageBind~\cite{girdhar2023imagebind}. We further build a complete end-to-end
pipeline that accepts a match video together with a set of query action clips
and produces a stitched highlight reel with per-clip timestamps and confidence
scores.

% ─────────────────────────────────────────────────────────────────────────────
\section{Problem Definition}
% ─────────────────────────────────────────────────────────────────────────────

\paragraph{Task.}
Let $V = \{f_1, \ldots, f_T\}$ be a target video of $T$ temporally ordered
segments and $Q = \{q_1, \ldots, q_k\}$ be a short query video depicting action
category $c$. The goal is to predict a ranked set of temporal windows
$\{(s_i, e_i)\}_{i=1}^K$ in $V$ such that action $c$ occurs in
$[s_i, e_i]$, evaluated by temporal intersection-over-union with ground-truth
annotations.

\paragraph{Dataset.}
We use the \textbf{SportsMoments} dataset, a 29-class collection of cricket and
football action clips sourced from YouTube. The dataset contains
\textbf{750,393 training} and \textbf{10,000 validation} samples. Each sample
pairs a target video segment with a query video and ground-truth temporal span.
The 29 action classes span both cricket (\textit{e.g.}, six, four, lbw, stumping,
yorker, pull shot, sweep shot) and football (\textit{e.g.}, goal, save, red
card, free kick, header, penalty). Video filenames encode the YouTube ID,
class ID, and clip ID in the format \texttt{\{YouTubeID\_\_classID\_videoID\}.mp4}.

\paragraph{Evaluation Metrics.}
Following standard moment retrieval practice~\cite{lei2021qvhighlights} we report:
\begin{itemize}[leftmargin=*,noitemsep]
  \item \textbf{R1@IoU}: Recall@1 at IoU thresholds 0.5 and 0.7.
  \item \textbf{mAP}: mean Average Precision averaged over IoU $\in [0.5, 0.95]$.
  \item \textbf{mIoU}: mean IoU of top-1 predictions.
\end{itemize}

% ─────────────────────────────────────────────────────────────────────────────
\section{Proposed Solution}
% ─────────────────────────────────────────────────────────────────────────────

\subsection{Model Architecture}

We use MATR~\cite{kumar2025matr}, a transformer encoder-decoder model for
cross-modal video-to-video alignment. Fig.~\ref{fig:architecture} shows the
overall architecture.

\begin{figure}[t]
  \centering
  \includegraphics[width=\linewidth]{../assets/model.png}
  \caption{MATR architecture. Target and query video features are jointly
  encoded by a transformer encoder. A decoder with learnable queries produces
  per-segment foreground scores and span offsets.}
  \label{fig:architecture}
\end{figure}

\paragraph{Input Projection.}
Target and query features are independently projected to a shared hidden
dimension $d$ via two-layer linear projectors with layer normalisation and
dropout ($p=0.5$). Temporal endpoint features (TEF)—normalised start/end
timestamps—are concatenated to the target features to inject positional context.

\paragraph{Encoder.}
A 4-layer transformer encoder with 8 attention heads and feed-forward
dimension $d{=}1024$ performs joint cross-modal reasoning over the concatenated
target and query token sequence using sinusoidal positional embeddings.

\paragraph{Dual-Stage DTW Alignment.}
At the heart of MATR is a two-stage Dynamic Time Warping (DTW) alignment
strategy applied before and after the encoder. Pre-fusion alignment enhances
the semantic representation of target and query features before they enter the
encoder. Post-fusion alignment refines target features conditioned on the
query using the encoder output, enabling fine-grained temporal matching. Both
stages use soft-DTW, which is differentiable and robust
to action speed variation.

\paragraph{Output Heads.}
Two convolutional prediction heads (kernel size~3, 3~layers) operating over the
combined encoder-decoder output produce: (1)~a per-segment foreground
probability $\hat{f}_i \in [0,1]$ (sigmoid BCE), and (2)~a per-segment span
offset $(\hat{d}^L_i, \hat{d}^R_i)$ trained with smooth-L1 and GIoU loss.

\paragraph{Loss Function.}
\begin{equation}
  \mathcal{L} = \lambda_b\,\mathcal{L}_{\text{boundary}}
              + \lambda_g\,\mathcal{L}_{\text{GIoU}}
              + \lambda_f\,\mathcal{L}_{\text{foreground}}
              + \lambda_s\,\mathcal{L}_{\text{saliency}}
\end{equation}
Boundary loss is smooth-L1 span regression, GIoU loss encourages better
overlap, foreground loss is binary cross-entropy, and saliency loss is an
inter-video contrastive objective.
All $\lambda$-coefficients are set to 1 except $\lambda_s{=}0$
(saliency disabled in our runs).

\subsection{Feature Encoders}

\paragraph{CLIP (ViT-B/32, 512-dim).}
Frames are sampled at the centre of each 2-second segment and encoded with the
frozen CLIP image encoder~\cite{radford2021clip}. The resulting 512-dim
per-segment features capture high-level visual semantics but contain no audio
information. This is the feature type used in the original MATR paper.

\paragraph{ImageBind (1024-dim).}
We extract fused vision+audio embeddings using the frozen ImageBind
model~\cite{girdhar2023imagebind}. For each 2-second segment we
(i)~extract the centre frame as the vision input, and (ii)~extract and
resample the audio waveform to 16\,kHz before computing a mel-spectrogram
(128 bins, 204 frames). Both modalities are encoded independently through
ImageBind's unified embedding space and averaged into a single 1024-dim
vector, which is then $\ell_2$-normalised. If a video clip has no audio
track, we fall back to the vision-only embedding. Many cricket
actions carry strong audio signatures (\textit{e.g.}, the crack of bat on ball
for a six, the wicket-keeper's gloves for a stumping, crowd roar for a six),
making audio a highly discriminative modality for this domain.

\subsection{Highlight Generation Pipeline}

The inference pipeline handles unseen match videos end-to-end:

\textbf{(1) Sliding-window feature extraction.}
The match video is divided into non-overlapping 2-second segments. Features are
extracted per segment using the chosen encoder (CLIP or ImageBind) and passed
to the model in windows of 75 segments (150 seconds) with 50\% overlap
(stride\,=\,38 segments) to avoid boundary artefacts on long videos.

\textbf{(2) Multi-query aggregation.}
For each action class, up to 5 query videos (sampled from SportsMoments query
clips of the corresponding class) are run through the model independently.
Windows confirmed by multiple queries receive a proportional confidence boost:
\begin{equation}
  c_{\text{boosted}} = c \cdot \left(1 + \frac{\text{votes}}{N_{\text{queries}}}\right)
\end{equation}
This boosts precision substantially—in qualitative testing the maximum
confidence for six detection rose from $\approx$0.18 (single query) to
$\approx$0.44 (5~queries), reflecting a $2.4\times$ gain from multi-query
consensus.

\textbf{(3) Non-maximum suppression.}
Windows are ranked by boosted confidence and NMS (IoU threshold\,=\,0.5) is
applied per class to remove duplicates. The top-$k$ windows (default $k{=}5$)
are retained per class.

\textbf{(4) Clip trimming and stitching.}
Retained windows are trimmed from the source video using \texttt{ffmpeg} and
concatenated in chronological order into a highlight reel. A
\texttt{summary.json} records per-query predictions with timestamps and
confidence scores.

\section{Experiments}
% ─────────────────────────────────────────────────────────────────────────────

\paragraph{Hardware.}
Training used a single NVIDIA RTX~6000~Ada (48\,GB VRAM). Feature extraction
and inference used a dedicated NVIDIA RTX~4000~Ada (20\,GB VRAM), running in
parallel with training.

\paragraph{Training Configuration.}
Table~\ref{tab:hyperparam} lists the key hyperparameters for both feature
variants. The ImageBind model uses a lower learning rate ($5\!\times\!10^{-6}$)
and larger hidden dimension to accommodate the 1024-dim input; the CLIP model
uses $10^{-5}$. Both models are trained from random initialisation (no
pre-training checkpoint) for 50 epochs with evaluation every 2 epochs.
Training throughput is approximately 2.3 hours/epoch for ImageBind and
1.1 hours/epoch for CLIP at batch size 100.

\paragraph{Codebase Bug Fixes.}
The publicly released MATR codebase contained several bugs that prevented
training. We identified and fixed six issues:
\textbf{(a)}~Missing \texttt{start\_end\_collate\_mr} and
\texttt{prepare\_batch\_inputs\_mr} functions in \texttt{dataset.py}
(imported by \texttt{train.py} but never defined);
\textbf{(b)}~broken imports (\texttt{nncore}, \texttt{config\_hl},
\texttt{pad\_sequences\_1d}) and an \texttt{IndentationError} in
\texttt{dataset.py};
\textbf{(c)}~incorrect forward-signature argument names in \texttt{matr.py}
(\texttt{query\_feat}/\texttt{video\_feat} vs.\ the expected
\texttt{src\_txt}/\texttt{src\_vid}) and all-zeros mask generation (should be
all-ones for the valid-token convention);
\textbf{(d)}~a broken loop in \texttt{align\_transformer.py} that iterated
over the video-length dimension when building per-batch DTW samples, causing an
\texttt{IndexError} at runtime; the result was unused, so we replaced the block
with a direct pass-through;
\textbf{(e)}~a wrong dict key \texttt{model\_inputs["src\_vid\_mask"]}
in \texttt{inference\_mr.py} (correct: \texttt{targets["timestamp\_mask"]});
\textbf{(f)}~missing \texttt{max}/\texttt{min} attributes on
\texttt{AverageMeter}, required by \texttt{train.py} epoch logging.

\paragraph{Effect of Audio Modality in ImageBind.}
ImageBind embeds both vision and audio into a joint space. Cricket actions
carry highly discriminative audio signatures—the crack of bat on ball for a six,
the wicket-keeper's gloves for a stumping, the umpire's call for an lbw. By
fusing audio and vision into a single 1024-dim embedding, ImageBind implicitly
provides an audio-informed query representation that CLIP's vision-only encoder
cannot replicate.

\paragraph{Training Stability Across Epochs.}
Fig.~\ref{fig:curves} shows that the ImageBind model converges rapidly
(peak at epoch~3) whereas the CLIP model degrades after epoch~3. Both exhibit
the same pathology: foreground loss $\mathcal{L}_f$ increases monotonically
after the peak while validation metrics fall, indicating that the learning rate
($5\!\times\!10^{-6}$ for IB, $10^{-5}$ for CLIP) remains too high for
extended fine-grained regression learning. The scheduled LR drop at epoch~40
is expected to stabilise later checkpoints.

\paragraph{Comparison with Paper's Encoder Ablation.}
The original MATR paper reports only CLIP-based results on SportsMoments
(Trained+V: R1\,=\,52.7, mIoU\,=\,56.2). Our CLIP replication at epoch~3
achieves R1\,=\,49.3 and mIoU\,=\,43.5—within 3.4\,pp on R1 but lagging
mIoU by 12.7\,pp, likely because the paper uses 200 training epochs and
Kinetics700 pre-training. The ImageBind variant (+19.8\,pp R1 over our CLIP)
demonstrates that richer multi-modal features substantially improve V2VMR for
sports, suggesting a promising direction for extending the original paper.

\subsection{Key Observations}

\paragraph{ImageBind substantially outperforms CLIP.}
At their respective best epochs, ImageBind achieves R1@0.5\,=\,69.1 vs.\
49.3 for CLIP—a relative improvement of 40\%. The audio modality provides
discriminative cues absent from visual features alone that are highly aligned
with cricket action categories.

\paragraph{R1@0.5 already exceeds the paper's best SportsMoments baseline.}
Our ImageBind model surpasses the paper's Finetuned+V R1@0.5 of 56.5 at
just epoch~3 of our 50-epoch run, without any pre-training or data
augmentation.

\paragraph{mIoU nearly matches the paper.}
Our mIoU of 57.2 is just 2.0\,pp below the paper's best Finetuned+V mIoU of
59.2, and \textbf{1.0\,pp above} the Trained+V mIoU of 56.2, again at epoch~3.

\paragraph{Multi-query boosting improves highlight precision.}
Using 5 query videos per class during inference raised maximum confidence for
six detection from $\approx$0.18 to $\approx$0.44, significantly reducing
false positives in the highlight reel.

\section{Conclusion}
% ─────────────────────────────────────────────────────────────────────────────

We have applied MATR to automated cricket highlight generation on the
SportsMoments dataset, comparing CLIP and ImageBind feature encoders. Our key
findings are: (1)~ImageBind features yield substantially better retrieval
performance than CLIP (+19.8\,pp R1@0.5, +13.7\,pp mIoU), driven by the
discriminative audio signatures present in cricket footage; (2)~our ImageBind
model at epoch~3 already surpasses the paper's best SportsMoments R1@0.5
(69.1 vs.\ 56.5) without pre-training; and (3)~a multi-query aggregation
strategy boosts inference-time precision by up to $2.4\times$ in confidence.

Future work will: (a)~complete training to 50 epochs with the scheduled LR
drop at epoch~40; (b)~enable the saliency contrastive loss ($\lambda_s > 0$)
to improve foreground discrimination; (c)~experiment with lower learning rates
after the peak to prevent regression head divergence; and (d)~evaluate the
full end-to-end highlight pipeline on complete match videos.
